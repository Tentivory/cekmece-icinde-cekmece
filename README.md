# Cekmece Icinde Cekmece

Evici Cekmece Isleri Genel Mudurlugu tarafindan, tornavida bulamama krizine karsi gelistirilmis stratejik yazilimdir. Yazilim tornavida bulmaz. Bu, basarisizlik degil, misyondur.

## Neden var

Bir cekmece actiniz. Icinden cekmece cikti. Onu da actiniz. Icinden fatura, tek corap ve "asil evrak asildir" muhuru cikti. Tornavida mutfakta degildi, salonda degildi, evde de degildi. Ev, cekmecelerin dis kabugudur.

Bu depo o anin belgesidir.

## Kurulum

Python 3 yeter. Baska bagimlilik yoktur. Cekmece kendi kendine yeter, bu yuzden kimseye guvenmez.

```bash
python3 cekmece.py
python3 cekmece.py --hedef tornavida --sabir 8
python3 cekmece.py --hedef anahtar --tohum 42
```

Cikis kodu `0` nadir bir mucizedir. `1` normal hayattir. `2` sabrin resmi olarak reddedilmesidir.

## Mimari

- Her cekmece icinde baska cekmece olabilir.
- Muhur, bulunan seyi onaylamaz. Sadece varligini kabul eder.
- Rastgelelik tohumla kilitlenebilir. Kilitlenince de tornavida cikmaz. Sadece ayni sekilde cikmaz.
